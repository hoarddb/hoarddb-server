# The functions that may call bson.TrustStored, read by
# TestTrustStoredIsCalledOnlyFromStorageReads (trust_stored_allowlist_test.go).
#
# TrustStored checks only a document's framing. It is for bytes this node read
# back from its own store; bytes from a client, a peer, a restore file, a
# migration stream or a WAL record go through bson.Validate at the site's
# limit (server/nesting_depth.go:validateAt). Adding a line here is a reviewed
# change: name the storage read, and why its bytes are this node's own.
#
# One entry per line: the file relative to the hoardDB module root, a colon,
# and the enclosing function, a method written (*Type).Method.
